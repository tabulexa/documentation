# Release notes

## Version 3.0.1.0

- Improved projector icon contrast in light theme, preserving the dark-theme and active-orange styling.
- Configured optional replay using `ShowReplayMode`, disabled by default so imported slides are shown complete.
- Preserved live ink preview on the projector, native drawing and PPTX import/save behaviour.
- Updated the MSIX version to the Microsoft Store-compliant `3.0.1.0` format.

## Milestone 3 foundation

- Startup splash dismissal based on readiness rather than a fixed timeout.
- Improved handling of temporary PowerPoint rendering cache and malformed settings.
- Projector synchronization, original PowerPoint import, optional animated ink groups and per-slide annotations.

Some specialised drawing and presentation features require Windows hardware testing; releases should be tested on the target teaching configuration.
