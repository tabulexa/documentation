# **Buttons in the toolbar**

![images](/documentation/assets/images/topbar.jpg)

The top toolbar provides editing tools for the board. It is only visible in the local interface of the lecturer. 

<img src="/documentation/assets/images/buttons.jpg" width="200" style="float: right;">

- There are three different types of pens. The **"Pen"** button provides a normal round tip, the **"Pencil"** is pressure sensitive and you can tilt it, and the **"Calligraphic pen"** has an elliptical tip. You can change the side ratio and angle of the ellipse in the settings section.
- The buttons “New Page”, “Delete Page” and “Clear Page” create, remove and clear the current page
- You can change the current page with the **"Previous page"** and **"Next page"** buttons or select the page by clicking on the page numbers in the middle. A new page is created when pressing **"Next page"** on the last page of the document.
- The toolbar section to edit blocks of ink strokes is only accessible in EDIT mode.  **"Show blocks"** indicates the current blocks with a boarder and displays the editing buttons. **"Next block"** creates a new block, for the following ink strokes. The **"Lasso"** allows you to select strokes and add them to the current block.
- The **"Pointers"** button toggles a round pointer in the projection window. You can change the color and size of the pointer on the settings page. The pointer symbol will only show if the mouse is within the board area, or if the digital pen is close to the screen but not touching.  
- The strokes of your current page of your board will be saved whenever you change the page or navigate the archive. In addition, you can actively save the current page by pressing the **"Save"** button. 

Please see the paragraph below for the **"Adjust side ratio"** button.



## Side ratio of the projection window

Providing an easy way to match the side ratio between the projector and an existing document was probably the trickiest part when writing the app. It helps to choose the correct ratio already during the preparation of the lecture.

Each document has a **permanent side ratio**, which applies to all pages of the document, and which can be changed with the **“Adjust side ratio”** button. Please note that the flyout menu of the button shows various resolutions, but it is the side-ratio and not the pixel resolution that is relevant for the app. The resolution values are just given as examples for typical projectors.

The border of the active area is indicated by a dashed grey line in the main interface. Changing the side-ratio will adjust the width of the active area but not the height. Any existing text will be left-aligned after a change. Modifying the side-ratio will not remove any strokes, but just change the visible area of the document.

Opening a projection window will change the **displayed side-ratio** in the main interface and match it to the projection window. This is indicated by a **coloured border** around the active area. Again, the app will adjust only the horizontal width of the active area to match the side ratios. The permanent side-ratio of the document re-applies once the projection window is closed.

It is helpful to choose already during the preparation of the lecture a side ratio which is close to the ratio of the projector. If in doubt, take a ratio with a smaller width to avoid losing information during the lecture.
