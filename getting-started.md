# Getting started

On the Tabulexa Board startup dashboard you can choose:

1. **New board** — select a background and aspect ratio and start a blank lecture board.
2. **Open PowerPoint** — browse for a `.pptx` presentation.
3. **Recent presentations** — reopen one of the three most recent available presentation files.
4. **Settings** — choose theme, input, board, pointer and (when enabled) replay settings.

Opening PowerPoint may take a little time while slides and backgrounds are prepared. The loading overlay displays progress stages.

![Illustrative startup screen]({{ '/assets/images/start-page-illustration.png' | relative_url }})

## Basic lecture workflow

- Start a board or open a PPTX.
- Draw on the lecturer board with pen, mouse or both.
- Open **Projector** to show students a separate view.
- Use slide navigation arrows to move through the lesson.
- Save your annotations when leaving the board.
