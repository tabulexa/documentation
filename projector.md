# Projector & digital ink

Tabulexa Board has **two separate windows**:

- **Lecturer board:** the instructor's working view, with drawing tools and navigation.
- **Projector screen:** the student-facing window, which displays the lecture content without lecturer-only replay guides.

**Zoom and pan are decoupled:** the lecturer can adjust their working view without changing the student's projected view.

![Illustration of lecturer and projector windows]({{ '/assets/images/lecturer-projector-illustration.png' | relative_url }})

## Live ink projection

When the projector is open, completed ink is synchronised to the student view. Current versions also include a temporary live stroke preview so handwriting can appear while it is being drawn. When the stroke ends, the projector uses the finished native stroke. Stylus response can depend on the input hardware and driver.

## Input modes

| Mode | Use |
|---|---|
| Pen | Stylus drawing |
| Mouse | Mouse drawing |
| Pen & Mouse | Both; default |
| Hand | Pan and zoom without drawing |

## Using the projector

1. Connect your additional display in Windows.
2. Select **Projector** on the lecturer toolbar.
3. Move the separate projector window to the intended display if needed.
4. Use the independent lecturer board for teaching and navigation.

The projector pointer can be configured in **Settings → Pointer**. Available designs include Disc, Ball, Cross and Meteor.
